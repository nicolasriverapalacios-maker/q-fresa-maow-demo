# Q Fresa Maow - demo de sitio web

Demo visual pública de una página para Q Fresa Maow, Cancún. Incluye menú ilustrativo, armador de pedidos, mapa de referencia y enlaces al perfil oficial.

El armador muestra el pedido, pero no envía a un destinatario hasta que el negocio confirme su número de WhatsApp de pedidos. El cliente debe revisar y enviar el mensaje en WhatsApp. Las fotos y el menú son ilustrativos; la ubicación exacta, horarios y precios deben confirmarse con el negocio.
