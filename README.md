# Q Fresa Maow - demo de sitio web

Demo visual pública de una página para Q Fresa Maow, Cancún. Incluye menú ilustrativo, armador de pedidos, mapa de referencia y enlaces al perfil oficial.

El pedido se abre en WhatsApp con productos, cantidades e indicaciones prellenados; el cliente debe pulsar Enviar. La demo usa el número +52 998 215 7033 compartido por el usuario desde un contacto «Maow». El negocio debe confirmar que ese número recibe pedidos antes de usar la página como sitio oficial. Las fotos, productos, ubicación y precios aún requieren validación.
